# cpd-tlg: our CPD course materials

One subfolder per course. Each has `submit-to-cpd/` (the files to upload to The CPD Group portal, nothing else), `working-files/` (originals, PDFs, figure sources, critiques, fix logs) and a checklist for Jess.

- `builder-gel-course/`: Builder Gel Overlay and Short Extension CPD Course (#22521). Manual v1.1 and the B02–B06 pack ready for Jess's review; see `JESS - what to do in each file.docx`.

Background, the assessors' feedback on every course and The CPD Group's own templates are in `../cpddocs/` (start at its README) and summarised for the knowledge server in `../knowledge/cpd-accreditation.md`.

The build scripts for the figures and the v1.1 edits were session scratch files, not kept; the figures themselves are in `working-files/figures/`. Course manuals are edited in Word from here on.
